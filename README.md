# Day 7 - Modern & Asynchronous JavaScript

## Overview

This project contains my Day 7 JavaScript exercises and mini challenge.

## Topics Practiced

- Arrow functions
- Synchronous and asynchronous JavaScript
- Promises
- `resolve()` and `reject()`
- `.then()` and `.catch()`
- `async/await`
- `try/catch`
- `setTimeout()`
- Loading and error states

## Exercises

The exercises covered:

1. Converting normal functions to arrow functions
2. Creating a Promise that resolves after 2 seconds
3. Creating a Promise that rejects and handling the error
4. Using `.then()` and `.catch()`
5. Rewriting Promise logic using `async/await` and `try/catch`
6. Using `setTimeout()` to simulate a slow operation

## Mini Challenge

### Simulated User Loader

The mini challenge is a simple user loader that simulates loading data.

It:

- Shows a loading message
- Waits for 2 seconds
- Displays predefined users when successful
- Simulates a possible failure
- Displays a friendly error message
- Removes the loading message after the operation

## Technologies Used

- HTML
- JavaScript

## How to Run

1. Open the project in VS Code.
2. Open `index.html` in a web browser.
3. Click the **Load Users** button.
4. Open the browser Developer Tools and check the Console to see the JavaScript exercise results.

## What I Learned

I learned how JavaScript handles asynchronous operations using Promises and `async/await`. I also practiced handling successful and failed operations using `try/catch` and `finally`.
